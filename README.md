# Zombie Avoidance Game

## Project Description
This project is a basic Python prototype exploring the movement logic for a Zombie Avoidance Game.

## Algorithm Used
The current implementation uses a greedy, rule-based movement approach. The zombie selects a direction that reduces the distance to the player's position.

## Technology Used
- Python

## Project Status
Basic prototype. Further development is needed to create a complete playable game.

Note: A* and Dijkstra algorithms are not used in the current implementation.
